## RouteEval

I built a benchmark for LLM tool calling in running-route generation: **13 frontier models, 50 prompts, 16 runs each, 10,373 evaluations.**

The headline result: this is still hard for everyone. The best model (GPT-5) averaged **0.650** accuracy against its distance target and produced a near-exact route only **12.2%** of the time. Most models land near 0.5 — roughly a 50% distance error on a task that sounds trivial.
